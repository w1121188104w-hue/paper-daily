# 文献分类与翻译前筛选

更新日期：2026-09-08，规则版本2。本轮未重新采集、调用翻译服务、上传或部署。

## 现在有什么变化

页面默认展示“研究论文候选”，不再把所有收录条目都称为研究论文。在“文献类型”中可以切换查看全部记录、期刊资料、疑似更正通知、疑似撤稿通知和待人工核查记录。

类型能与期刊、学科、关键词和首次发现日期叠加。日历和列表使用同一筛选条件，进入日期详情再返回也保留类型。“重置筛选”返回默认研究候选范围。顶部始终说明完整库的记录总数。

每张卡片显示类型，并有“为什么这样分类？”说明。通知类卡片另行提醒：这是疑似通知，不代表系统已经核实另一篇论文被撤稿，也不会自动删除或合并原论文。

## 规则及保护边界

- 保留目录、封面、编委会等精确标题规则。
- 识别完整标题“Issue Information”及已经见到的期刊信息征稿附页，不因研究题目包含“information”或“papers”就排除。
- 编务标题限定期刊：JAE的“Editorial data”、JPE的“JPE Turnaround Times／Recent Referees”、JF的“AMERICAN FINANCE ASSOCIATION／ANNOUNCEMENTS”。相同词出现在别刊或更长研究题目中，不直接套用规则。
- 更正／撤稿通知优先根据标题或明确的来源类型识别，保留通知本身。
- 其他附属资料、编者文字或明确书评类型先待人工核查，不直接删除；综述类型“review”仍保留为研究候选。
- 不单凭缺作者、缺摘要或题目短来排除。来源分类不一致时保留待核查或通知提醒，不贸然判为期刊资料。

分类读取已保存的来源信息，仅在展示和导出时计算，没有向外部服务发送数据进行AI分类。

## 翻译导出增加保护

原有正式队列仍是814个待处理字段，保持旧版本校验兼容。现在另算两个范围：

- 默认可导出：471条研究候选、798个字段，其中471个标题、327个摘要。
- 暂缓：16条资料或通知、16个标题字段。

导出先筛研究候选，再应用每批数量限制，避免公告占掉名额。没有摘要的候选仍可导出标题，不补造摘要。资料、通知和待核查记录暂不进入新批次。现有已导出的批次和旧译文不会被删除。

查看队列及导入操作见[第四阶段说明](phase-4-report.md)。`node scripts/translations.js --queue`同时显示完整历史队列和当前导出资格；814和798的差额不是任务丢失。本轮没有导出真实批次或保存译文。
