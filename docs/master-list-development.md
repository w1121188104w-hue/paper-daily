| 搜索来源 | 智谱 Web Search、SerpAPI Scholar、SerpAPI Google；返回待验证线索，绝不把snippet当摘要 | 单元测试，尚无真实收费请求 |
| 搜索顺序 | 智谱→Scholar→Google；只有当前问题经原始来源确认后才停止；额度耗尽与未找到分开 | 已实现可注入验证器的协调器，尚未连接正式字段写入 |
| 额度保护 | SerpAPI每自然月最多250，同时受真实免费套餐周期与剩余额度约束；智谱默认预算0 | 离线测试；没有绑定任何线上密钥或付费方案 |

`src/services/masterList.js` 是旧论文库的兼容投影，不是第二个可以随意修改的事实库。事实仍来自 `papers/source_records`，读写时重算核对，篡改总名册会导致校验失败。`master-list.json` 和 `repair-state.json` 都由正式版本清单以SHA256引用，Git历史清单会一起保留。

新 `discovered_at` 使用第一次发现批次的时间，之后不改写。若旧数据只有 `first_seen_date`，则总名册的 `discovered_at` 为null、精度为day；不会把升级时间冒充首次发现时间。为兼容既有验证与翻译，旧事实库中的空文本暂不批量改成null，总名册对外字段采用null。

来源标记区分“独立检索发现”和“拿已知DOI查到信息”：旧Crossref/OpenAlex独立采集行、S2独立检索证据、官网清单核对报告才计入发现。摘要查页、按DOI查询不会抬高独立发现数。

月份优先采用有明确来源的在线发表信息，再看纸刊和未区分类型的出版信息。同一类型的来源月份冲突时保留证据并进入待办，不随便选较长文本或投票覆盖。仅有在线年份时不会用次年的纸刊月份代替；月份处于60天边界时标记boundary_uncertain，不生成虚构的1号发表日期。总名册统计是全部保留历史，`window_status` 单独标记最近一次采集范围；每轮发现并集另见日志 `discovery_summary`。

## 只读查看（无网络、无密钥、无写入）

```powershell
node scripts/master-list.js --status
node scripts/master-list.js --list --journal AER
node scripts/master-list.js --unresolved
node scripts/master-list.js --unresolved --due
```

待办输出含论文ID、标题、DOI、问题原因、尝试历史、下次重试时间，供未来Codex集中处理。`manual_review_required` 固定false：不是等待人工审批的流程节点。

旧库尚未保存总名册快照时，status中的 `persisted` 为false；只读查看不会悄悄迁移或写库。本机历史版本可能落后于GitHub，因此本机条数不是线上实时条数。

以下命令会联网并保存本地正式库，仅在准备完成且明确需要时执行；本轮没有执行它来改写实际数据：

```powershell
node scripts/journal-library.js --collect --save --all --lookback-days 60 --with-semantic-scholar
```

不带第三源开关，原来的双源行为保留。启用三源时，“今天双源已经成功”不会误判为“三源已经完成”。一个来源失败仍保留其他来源取得的有效记录并标注部分失败。

## 搜索与费用的安全边界

- `searchSources.js`不读取环境变量，不在导入时联网；实际调用需显式传入密钥。
- 智谱仅调用Web Search，不调用聊天模型、Search Agent或任何摘要生成模型。
- 搜索结果中的网页摘要以snippet保存为线索，不允许作为论文Abstract写库。长标题因智谱70字查询上限使用前缀查询，但后续身份核对仍必须使用完整标题。
- 搜索入口提供期刊＋月份查询，后续整篇漏收修复不能只搜索已知论文标题。
- 固定认证主机、禁止携带密钥跳转、请求超时和响应体上限，不回显远程错误正文。
- SerpAPI账户接口会回显密钥、邮箱；代码只保留免费额度相关的白名单字段。
- SerpAPI需确认免费方案、没有额外付费额度、账户状态正常；套餐或额度不明即停止。Scholar和Google共用250上限，不各算250。
- 本地自然月上限与账户实际续期周期同时生效，不能到每月1日就自行认定账户免费额度已恢复。
- 账本必须先持久化并完成生产远端检查点，再发收费请求；结算不明继续占用额度，同一未知结果请求24小时内不重发。冷却后可以在剩余预算允许时自动重试，旧预占仍保留，不永久要求人工解锁。
- `makeBudgetedSearch`负责单次运行内串行化；正式接线仍须共享生产写锁并复用远端检查点流程，不能拿空实现的persist函数上线。
- 智谱月预算默认0，未获预算确认之前不启用请求；没有自动充值、购买额度或升级套餐的代码。
- 缓存/失败请求的官方计费只有明确确认后才能释放本地预占；目前搜索适配器对成功请求保守记1次，不根据耗时猜测免费缓存。
