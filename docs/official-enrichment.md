# 官网核对与真实摘要补全

本轮范围由用户确认：**最近60天，每日滚动核对，不追溯更早的首次发表论文**。例如2026-09-11核对2026-07-14至2026-09-11。摘要补全则检查现有库里的缺摘要记录，不受60天限制。

## 现在的功能

日常顺序：Crossref＋OpenAlex采集 → 原有合并去重 → 官方目录／订阅清单核对 → 补入能够核实的漏收研究候选 → 查找真实英文摘要 → DeepSeek翻译已有英文 → 更新原网站。所有摘要均来自来源原文，程序不调用AI生成或概括英文摘要；英文为空时不会生成中文摘要。

官网核对优先匹配DOI；没有DOI时，使用规范化标题、作者、期刊和日期。标题大小写、标点、连字符及作者姓名顺序差异不应制造重复。身份冲突、日期边界不确定、信息不足均列入待核实，不直接入库。期刊资料、明确编辑报告、更正及撤稿通知不计作本次补入的研究论文。

**订阅更新时间不等于发表时间。** Wiley的目录订阅会在论文编入纸刊时重新标注日期，Elsevier订阅还会提供未来的封面月份。因此，RSS/DC日期只能作为线索；新发现记录必须通过DOI元数据或经过身份核验的正式文章页面确认发表日期。日期只有月或年时保留原精度，不能凭空补成1号。

摘要依次查询Crossref、OpenAlex、Semantic Scholar，再尝试允许访问的官方订阅／文章页面。出版社专用接口目前没有配置，明确记录跳过，不冒充已经查过。只接受明确的abstract字段、经过核对的JSON-LD abstract或页面Abstract正文，不使用搜索摘要、description营销文字、Semantic Scholar TLDR或AI摘要。OpenAlex摘要位置缺失或冲突时拒绝拼接。

对已有记录，只允许填入空的英文摘要及其来源；标题、作者、发表日期、首次发现日和已有中文不变。新摘要进入现有翻译队列；不逐篇语义校对，不自动重试已经暂缓的同一翻译任务。

## 怎样查看

打开原来的论文日历，在“采集概况”下展开“官网漏收核对明细（最近60天）”。每本期刊分别列出：官网清单观察数量、窗口内确认数量、原库总数、确认漏收数、补入数、待核实数。

- “部分核对”：成功读取部分官方清单，**并不代表覆盖全部论文**。
- “访问受限／未核实”：不能读取有效清单；数量未知，不用0冒充。
- 摘要卡片显示真实来源链接；缺失时显示待补全、受限或稍后重试等状态。
- 日期日历继续按“系统首次发现日”归档，不改成发表日；补入旧的窗口内论文也记在实际发现日。

未找到摘要会按约1、3、7、14、30天间隔重新尝试，尊重来源的限流等待时间。每天最多检查100篇到期缺摘要记录，首次手动补全最多1000篇；已完成英文摘要不会重查。13:17任务仅处理仍需要采集或已到期的补全，不反复全文重跑。

## 核对范围的限制

本次实现覆盖全部19刊的官方来源映射，但**没有任何连接器被认证为完整目录覆盖**。公开RSS通常只提供少量最近文章，期刊目录可能分页、漏掉在线优先发表文章，部分网站存在机器人规则、403或登录重定向。程序遵守这些限制，不伪装浏览器、不绕过验证码、不把访问失败算成功。

当前可读取的公开表面包括美国经济学会已出版期次列表、Wiley及牛津大学出版社公开订阅。其他来源会保留真实失败原因。想进一步扩大官网覆盖，需要根据出版社提供的正式数据许可／接口逐个接入；这不影响已有双源采集、真实摘要补全及翻译正常工作。

Semantic Scholar公开接口在本机首轮返回429，因此当轮停止继续请求该站。可选的`SEMANTIC_SCHOLAR_API_KEY`只允许配置为GitHub Actions Secret；没有此密钥也能运行其余来源。目前不要求用户新增账号，也没有保存任何新密钥。

## 运维与数据保护

运行环境：Node.js 24（最低20.18.1），锁定Cheerio 1.2.0，仅解析HTML/XML，不执行页面脚本。API域名与官方期刊域名固定白名单，HTTPS、超时、正文大小、页数、总请求数和逐站间隔均有限制；429停止当轮同站请求。

只读查看：

```text
node scripts/enrich-library.js --status
```

明确执行和保存：

```text
node scripts/enrich-library.js --run --save --all --official --abstracts --lookback-days 60 --max-abstracts 100 --only-if-needed
```

小范围可将`--all`换成`--journal AER`。只运行官网检查用`--official`；只补摘要用`--abstracts`。默认无参数只显示帮助。CLI拒绝把核对期扩大到60天之外。

每日工作流新增独立开关`JOURNAL_ENRICHMENT_ENABLED`；关闭它只停本模块，不关闭原来的双源采集和翻译。`enrich-library.yml`是手动存量补全入口，与采集／翻译／发布共用`journal-production`串行锁，不监听推送，不产生循环。

每次补全使用独立`metadata_enrichment`不可变快照，不冒充双源采集成功。`enrichment-report.json`保存逐刊和逐篇明细，`enrichment-state.json`保存重试状态；通过正式历史引用及SHA-256校验保护，并被后续采集、翻译版本继续引用。来源记录保留原始摘要、实际取得时间、出处URL和响应正文哈希；不把密钥、请求头、验证页面或整个网页复制到网站。

仅允许使用正式历史白名单暂存数据。未提交尝试、临时试验和孤立快照不会自动进入Git或网页。所有报告统计属于实际可读取的来源和本次窗口，不能用于声称19刊100%不漏收。
