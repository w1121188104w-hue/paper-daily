# 正式采集闭环（0.12.0）

## 边界

本版把现有浏览器采集与正式库连接起来，不重建 UI，不替换三源或 DeepSeek 翻译。作者单位继续按原能力采集，不额外修复。JPE Just Accepted / 图片摘要仍停用，其最新卷期和 Ahead of Print 保留。

原自动采集、搜索补摘要、自动翻译任务继续暂停。新发现任务也默认关闭；部署代码不等于启用定时任务。

## 两种使用模式

- **日常增量**：网站待检查提醒 → 同步后只打开相关目录 → 原文核对 → 仅新论文和到期未完成论文进入详情队列。
- **全刊巡检**：用户每周或半月手动启动 → 所有启用期刊的最新一期及在线发表目录 → 与正式库去重 → 不重抓已完成的详情。

全刊巡检不是回溯全部历史卷期。提醒无法证明没有遗漏；索引和搜索可能延迟，所以定期巡检仍必要。

## 正式步骤

1. 运行仓库根目录的 `start-workflow.cmd`。它复用本机加密保存的 DeepSeek Key，不要求重新输入；启动本身不调用付费 API。
2. 扩展弹窗进入“正式流程”，同步提醒，选“日常增量”或“全刊巡检”。每个批次单独保存进度，不清除原测试结果。
3. 插件自动打开目录和论文；遇验证暂停，由用户完成。打不开时手动打开，再点扩展“读取本页并继续任务”。
4. DeepSeek 只核对已采集原文和字段证据，不生成缺失摘要。核对结果按证据复用缓存。
5. 详情完成后向本机正式服务提交。若提交失败，浏览器原始结果保留，可点“提交本批次结果”，亦可导出 JSON 备份。
6. 返回正式入口，明确点击“导入、翻译并发布”。服务重放证据校验、合并正式库，只翻译本批次缺失中文字段。每次最多 100 次翻译请求，成功字段不重复调用；未知计费结果不盲目重发。
7. 提交数据和回执，申请 Pages 发布。扩展显示“等待上线核验”；点击核验，必须在网站读到该批次、本次发布版本及输入摘要校验值，才标为已发布。
8. 尚有中文字段待处理时，可继续翻译并发布，不必重采；网页/摘要缺失另列待补，不伪装成完成。

关闭扩展面板暂停页面调度，重新进入同批次恢复。服务重启不会自动恢复付费导入/翻译，需用户再次明确执行。

## 提醒与回执

三源各自发现论文，已知 DOI 不反复提醒；新 DOI 触发该期刊的卷期和在线目录检查。搜索只提供官方目录/文章的更新线索，不追逐缺失摘要。搜索线索显示“疑似更新”，不能当作已核实新一期。

只有本批次成功读取、身份正确、分页完成且目录核对完成，才处理其启动时已有提醒。开始任务、访问失败、搜索无结果均不清除提醒；运行期间新增提醒也不被旧批次清除。目录检查完成与摘要补全是两个独立状态。

缺失论文保留 DOI、页面链接和目录归属，通常七天后重查相关目录。如果论文已离开原在线列表，它仍留在待补清单，不会当作成功；此时可以继续原批次的详情补采。网站同时显示监测失效/过期，不能把“没有提醒”理解为“没有新论文”。

## 在线发现开关（当前保持关闭）

新增 `collection-discovery.yml`：只有仓库变量 `JOURNAL_DISCOVERY_ENABLED=true` 才运行。独立三源每日滚动 60 天、保存来源与正式元数据，生成提醒并构建网站，不执行摘要搜索或翻译。

搜索另需 `JOURNAL_DISCOVERY_SEARCH_ENABLED=true`：智谱 Pro 优先，未发现可用线索才尝试 SerpAPI Scholar / Google。使用现有远端调用账本；智谱每月 2000 上限，SerpAPI 免费 250 上限，未核实免费账户不调用。每刊每轮每层至多一条目录查询，不按缺摘要论文数扩大查询。

计划时点为北京时间 08:17、13:17，GitHub 调度不保证准时。新开关需要首个正式批次验收后再明确开启，旧的付费任务不随之恢复。

## 存储与安全

- 正式提醒和回执：`data/collection-workflow/state.json`，随正式库提交。
- 原始浏览器批次：本机 `%LOCALAPPDATA%/PaperDailyWorkflow/<批次ID>/`，不发布到网站。
- Key 仍由现有 DPAPI 配置保存，不交给网页或写进仓库。
- 本机正式服务只监听 `127.0.0.1:17328`，限定配置的扩展 ID、Origin 和请求头，不接受任意路径、命令或远程地址。
- 发现任务默认关闭；网页加载、本机状态刷新和上线核验不调用 DeepSeek/搜索。

## 验收界限

离线测试覆盖提醒去重、增量范围、失败不销单、并发新信号、真实证据导入、模拟翻译、真实网站构建、分批翻译续跑和发布版本核验。它们不等于真实浏览器采集或 GitHub 发布成功。首次使用仍需选择一个小批次跑完并核验网站回执。
