# 浏览器结果导入：正式版

正常使用不需要导出、手动导入或本地翻译。请按 [正式闭环](collection-workflow.md) 启动一次采集，插件自动核对、上传，GitHub 统一翻译发布。

旧 `start-browser-import.cmd`、本地翻译脚本和交互导入向导已移除，避免误用第二套翻译入口。原始导出、论文库和历史账本保留。

## 只读维护入口

`node scripts/browser-import.js --file "导出文件.json" --library "本地库目录"`

默认只预检，不联网、不收费、不改库。管理员指定 `--save` 才导入，`--build "独立输出目录"` 可构建只读预览；不支持本地翻译，也不自动部署。这不是日常用户入口。

导入只接受实际采集且有匹配原文核对证据的文章。相同 DOI 去重；标题、期刊、DOI 冲突留待核实。已有非空摘要、日期、作者、译文不覆盖。缺失摘要不由模型生成。旧导出继续兼容，完整浏览器原文不上传网站。
