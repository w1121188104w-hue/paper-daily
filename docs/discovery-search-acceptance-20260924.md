# 新版搜索辅助发现：2026-09-24 测试结论

## 结论

**部分验证通过，尚未达到整体上线验收。** 实时搜索确实能找到新一期，经过目录基线比较后可生成对应期刊的增量提醒；但在线新增论文的搜索索引有延迟、结果片段缺少发表日期，不能把“搜索没有发现”当作“期刊没有更新”。

本次没有恢复旧采集、旧智谱搜索、翻译或发现任务，没有调用 SerpAPI，没有修改正式论文库，也没有发布网站。这里只验证搜索与提醒候选判断，不等于三源、网站提醒、插件导入的完整线上闭环已验收。

## 测试覆盖和真实发现

覆盖 18 本期刊，测试最新一期与在线发表查询：

- TAR、JAR、QJE、RP、MS、JM；
- AOS、JAE、CAR、RAS、AER、RES；
- JF、JFE、RFS、JCF、JIBS、JOM。

比较了普通关键词、站点限定、年份限定、原生域名过滤等查询。原生域名过滤与期刊全名组合更便于限定来源，但不能解决索引更新延迟。URL 查询和最近一个月过滤的最后两批被支付错误阻断，**没有有效实测结论**；已补充 URL 不得截断路径的本地测试。DOI 正向对照模式仅实现、未实际收费运行，不计入发现成效。

真实正例：JF（The Journal of Finance）的已采目录基线为 Volume 81, Issue 4。实测返回 Volume 81, Issue 5 / October 2026，独立读取 [Wiley 官方当前期页面](https://onlinelibrary.wiley.com/toc/15406261/current)确认。将实测结果与用户保存的目录基线离线回放，只生成 JF 对应的新一期候选；重复回放不新增提醒，基线更新为 81/5 后不再提醒。

证据运行：[35956037407](https://github.com/w1121188104w-hue/paper-daily/actions/runs/35956037407)。这里的基线比较和去重通过的是**离线回放**，尚未写入网站提醒状态。实际探针故意使用空工作流，不应把其输出误认为网站已经上线。

反例与边界：ScienceDirect 多本期刊的返回目录落后于用户已采目录；部分结果只是旧文章、参考文献提及目标刊、投稿说明或在线目录入口。找到已知在线文章标题只能说明该内容已被索引，不能换算成“新增论文召回率”。目前没有足够证据承诺搜索能及时覆盖所有新增在线论文。

## 本轮修复

- 核对目标出版社、期刊路径和适用的 DOI 前缀，拒绝参考文献造成的错刊线索。
- 目录按已确认卷期基线比较；旧卷期、同一期及没有更新证据的通用目录不提醒。
- 支持 SAGE 的 JOM 路径别名、明确的卷期文字，以及 Elsevier 只有卷号的 `/suppl/C` 路径。
- 修复 Oxford DOI 期刊段解析，不把文章内部数字 ID 当作 DOI 的一部分。
- 在线文章缺乏可信发表日期时保留未确认状态，不凭 DOI 年份或网页抓取日期猜测新旧。
- 将没有验证到新增线索的监测标为部分覆盖，不用 HTTP 成功冒充采集完整。
- 累计硬上限、先记账后调用、记账失败不调用、未知失败不释放预占、真实新一期去重均有本地回归测试。
- 最终本地全套测试：595 通过，0 失败；不是 595 次付费 API 调用。

## 后续验收所需

1. 把插件已核对的目录卷期/在线文章集合持久保存为发现基线，接入正式提醒流程；不能每次用空基线。
2. 三源增量和搜索都只生成有出处的目录提醒，搜索为辅助；不能只靠搜索决定是否启动插件。
3. 无可靠更新信号时显示“未确认/待巡检”，按用户选定的一周或半月安排全目录巡检，不能宣称无需巡检。
4. 账户可用后，剩余 20 次优先验证已知最新在线文章能否被搜到，并区分“搜索未索引”与“规则拒绝”。不再重复泛搜消耗额度。
5. 只有提醒 → 指定目录插件采集 → 去重合并 → 翻译 → 网站更新，并且重复执行不重复收费/入库得到端到端验证后，才谈恢复新版自动任务。旧搜索流程继续保持关闭。
