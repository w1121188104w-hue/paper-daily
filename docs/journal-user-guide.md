# 团队使用说明

网站：https://w1121188104w-hue.github.io/paper-daily/

直接把这个网址发给团队成员即可阅读，无需登录或提供 API 密钥。打开网页不会触发采集或产生翻译费用。

## 平时怎么看

1. 首页选择期刊或学科分类，默认查看“研究论文候选”。候选是自动分类结果，不是完整性保证。
2. 在日历选择日期查看论文。日历按系统首次发现日期排列，不代表论文当天发表；论文卡片另列有来源支持的发表年月。
3. 用搜索框查标题、作者或 DOI，结合期刊筛选缩小范围。
4. 有译文的摘要可以切换中英文；通过 DOI 或来源链接查看原始信息。
5. 想看更正、撤稿和期刊资料时，切换文献类型。这些记录仍保留，不会混作普通研究论文。

## 系统每天做什么

日常入口按北京时间08:17、13:17两个时段检查是否需要执行。GitHub调度、外部接口和翻译都有耗时，因此不是承诺该分钟网页立即更新，也不保证半小时内完成。

执行顺序为：Crossref、OpenAlex、Semantic Scholar独立发现 → 官网清单核对与搜索补漏 → 去重及总名册 → 缺字段补全 → DeepSeek翻译 → 更新网页。核对窗口为最近60天，已保存历史不会随窗口滚动删除。

搜索先用智谱Pro；仍未解决才用SerpAPI Scholar、Google。按后续授权，智谱已放开程序原先的每月2000次上限，仍受平台余额及接口限制；SerpAPI仍严格限制每月最多250次，并核对账户真实免费额度及续期时间，不会自动购买或升级套餐。

## 为什么还会看到缺失或待核实

出版社和数据库可能没有摘要、暂未收录或限制访问。系统只保存有来源的英文原摘要，不编写或改写摘要。没有英文摘要就不生成中文摘要，后续找到原文后再翻译。

CAR 如果只拿到了法文摘要，会显示“法文原文（英文待补）”，并计入缺英文摘要数量。法文原文及已有旧译文保留，英文标题可以先翻译，摘要等到找到出版社英文版本后再翻译；不能靠 AI 把法文翻回英文冒充作者原文。

月份不明、相似标题无法可靠去重、来源之间矛盾，也会保留记录和证据，进入自动待办。待办按间隔重试，不要求团队逐条人工审批。某次外部来源失败，不代表已取得的数据全部作废，也不能据此认定该期刊没有论文。

## 怎么判断更新情况

查看网页顶部的采集时间和数据保存时间：翻译保存时间不等于采集时间。若数据长期不更新，再查看[GitHub运行记录](https://github.com/w1121188104w-hue/paper-daily/actions/workflows/daily-collect.yml)。

GitHub任务标红可能是部分来源未完成或译文被暂缓，也可能是程序问题，要结合具体步骤和日志判断。不要为消除红色提示连续手动重跑，避免重复消耗额度。

程序和开关更新完成不等于网页已发布；上线验收以生产数据成功保存、网站部署成功及实际页面可用为准。
